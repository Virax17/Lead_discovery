<h1 style="color:red;">Lead Discovery Project</h1>

This repository contains the **Lead Discovery** backend service.

## Overview
- FastAPI based service
- Uses Google Places API
- Implements lead scoring and deduplication

## Getting Started
```bash
# Install dependencies
pip install -r backend/requirements.txt

# Run the API
uvicorn backend.app.main:app --reload
```
